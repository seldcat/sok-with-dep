[hotcrp] 
  You’ll be able to review the mails before they are sent.
Keywords enclosed in percent signs, such as %NAME% or %REVIEWDEADLINE%, are expanded for each mail. Use the following syntax:
%URL%
Site URL.
%LOGINURL%
URL for recipient to log in to the site.
%NUMSUBMITTED%
Number of papers submitted.
%NUMACCEPTED%
Number of papers accepted.
%NAME%
Full name of recipient.
%FIRST%, %LAST%
First and last names, if any, of recipient.
%EMAIL%
Email address of recipient.
%REVIEWDEADLINE%
Reviewing deadline appropriate for recipient.
%NUMBER%
Paper number relevant for mail.
%TITLE%
Paper title.
%TITLEHINT%
First couple words of paper title (useful for mail subject).
%OPT(AUTHORS)%
Paper authors (if recipient is allowed to see the authors).
%REVIEWS%
Pretty-printed paper reviews.
%COMMENTS%
Pretty-printed paper comments, if any.
%COMMENTS(tag)%
Comments tagged #tag, if any.
%IF(SHEPHERD)%...%ENDIF%
Include text if a shepherd is assigned.
%SHEPHERD%
Shepherd name and email, if any.
%SHEPHERDNAME%
Shepherd name, if any.
%SHEPHERDEMAIL%
Shepherd email, if any.
%IF(#tag)%...%ENDIF%
Include text if paper has tag tag.
%TAGVALUE(tag)%
Value of paper’s tag.
